# Inside the Impact

A fictional boxing safety-education simulation. You coach the corner: train the
fighter, read the signs between rounds, and decide when to stop the bout.

Created by Joohyun Lee.

**This is a game, not a medical tool.** Its indicators are fictional counters.
They cannot diagnose, exclude, locate or grade a real injury. For any suspected
injury, seek qualified medical assessment. Emergency services in South Korea: 119.

Play: https://inside-the-impact.pages.dev/
