# Integration notes: fightcam, index.js, arena.html, the index.html hook, audio.js, fx.js, HUD leftovers

Status: done and verified on the real page, except what "Rough or not verified" lists. Log at the bottom, newest last.

## What exists and how to use it
- `gfx/arena/index.js`: `openArena(opts)`, `closeArena()`, `arenaSession()`. Only hud.js is imported up front; everything else is a dynamic import counted as load progress, so the load screen shows straight after the click. Options: quality, adaptive, difficulty, names, seed, touch, manual, bot, botKind, onFail. `window.__arenaOpts` is merged underneath, for tests on the real launch path.
- Frame order: input, sim, rig, events (HUD, audio, fx, camera kick, lamp), HUD, audio, fx, camera, stage, render. The sim steps tick by tick and stops on the tick a punch connects, so the frame drawn and held by hit-stop is the contact. Sim and rig stop in hit-stop and slow down in slow motion. HUD, fx, camera, audio run on real time.
- `gfx/arena/fightcam.js`: `createFightCam(camera, { reducedMotion, shake, canvasY, stage })` -> `update, kick(power, dir), getFocus, basis, snap, setShake, shake, stats`. Fades corner posts through stage.setPostAlpha when they stand between the camera and a fighter or sit close to the lens.
- `gfx/arena/fx.js`: `createFx(scene, q, { stage, reducedMotion, onLand })` -> `impact(pos, dir, power, blocked, ev)` returns hit-stop seconds, `dust, onEvent, update, track(rigP, rigO), clear, applyQuality, dispose`.
- `gfx/arena/audio.js`: `createAudio({ enabled, volume, lite, ctx, seed })` -> `crowdReady, onEvent(ev, when), update(match, dt, when), land(when), unlock, setPaused, setVolume, setEnabled, newMatch, destroy`. The crowd renders in a worker and fades in. `gfx/dev/sound.html` is a sound board for a person to listen.
- `gfx/dev/arena.html`: dev page, `window.ARENA`. Query q, seed, bot, kind, ai, manual, touch, adaptive.
- `site/index.html`: three edits only. A head script `#arena-loader` that adds the import map and defines `window.__openRealArena(fallback)`; the launch line calls it with openArena3D; `.arena-x` added to hotkeysBlocked. The import map is added by JS because tools/jscheck.py parses every script block as JavaScript and a JSON block fails it.
- Test tools in the scratchpad `integrate/`: drive.py (one Chrome, screenshots when the page asks), play.js (bot presses real keys through the real launch path, measures gaps, feet, camera, memory, runs flow checks), show.py (prints a result file), cfg_*.js (config, passed with --prepend), fps.js, audio_test.js.
